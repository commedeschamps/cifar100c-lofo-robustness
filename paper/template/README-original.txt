
---ELECTRONIC LETTERS ON COMPUTER VISION AND IMAGE ANALYSIS (ELCVIA)---


* ELCVIA STYLE FILES IN LATEX 2e ----------------------------------

  - ELCVIA.STY: Style file (margins, captions, etc.),
               which use the style file ARTCAST.CLS

  - ARTiCLE.CLS: Standard style file in Latex2e.

  - ARTICLE.STY: Standard style file in Latex2e used with
                  'ARTICLE.CLS'.

  - ELCVIA2e.TEX: Sample file of ELCVIA article in Latex2e.

  - ELCVIA2e.PDF: Sample file of ELCVIA article in PDF format.

  - PSFIG.STY: Style file which allows to include EPS files
                in Latex files using

           \psfig{figure=file.eps,width=10cm} or
           \psfig{figure=file.eps,height=4cm}


* ELCVIA STYLE FILES IN LATEX 2.09 --------------------------------

  - ELCVIA.STY: Style File (margins, captions, etc.),
               which use the style file ARTICLE.STY

  - ELCVIA209.TEX: Sample file of ELCVIA article in Latex 2.09.

  - ELCVIA209.PDF: Sample file of ELCVIA article in PDF format.

  - PSFIG.STY: Style file which allows to include EPS files
                in Latex files using

           \psfig{figure=file.eps,width=10cm} or
           \psfig{figure=file.eps,height=4cm}

  - CREADY.TXT: Intructions to Camera Ready Format when the article
                is accepted.

  - README.STY: This file


* ELCVIA STYLE FILES IN WORD 2000 ----------------------------------

  - ELCVIA.DOC: Sample file of ELCVIA article in Word 2000

  - ELCVIA.PDF: Sample file of ELCVIA article in PDF format.

  - ELCVIA.DOT: ELCVIA Standard style file in Word 2000.
